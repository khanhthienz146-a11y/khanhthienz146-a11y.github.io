# Lloyd Tran — Portfolio

A bilingual (Vietnamese / English) static portfolio website built with HTML, CSS and vanilla JavaScript. No build step or paid hosting service is required.

## Files
- `index.html` — homepage and portfolio sections
- `app.js` — bilingual content, service interactions, project filters and case-page data
- `styles.css`, `project.css` — responsive visual system
- `project.html` — reusable project detail page
- `assets/mark.svg` — abstract brand mark

## Enable GitHub Pages
1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then click **Save**.
4. GitHub will publish the site at https://khanhthienz146-a11y.github.io/ once deployment finishes.

## Before the final public launch
- Add your two original portrait photos as `assets/portrait-about.jpg` and `assets/portrait-closing.jpg`. The matching image slots are in place; no substitute portraits have been generated.
- Project cards link to the source documents you supplied. Detailed case-study narratives and performance figures should only be added after reviewing those source materials.
- Google Fonts load when online; system fonts are used as fallback.
